## 冻结验收标准

* 数值：均匀介质总光学厚度不变，1/2/8/32 层合成误差 <= 1e-6（double
  参考），GPU RGBA16F <= 0.3% 或 2 个 half ULP；源=背景时不变。
* 视觉：普通固定映射下连续核心、自然边缘，无矩形/梳齿/翻转、整机随机跳亮。
  同波段 A/B 映射一致；用户审美签收单列，不能由工程 PASS 代替。
* 闪烁：固定物理状态、噪声关；平移用已知运动补偿；一般场景需要可靠重投影，
  没有几何对应就不输出“已补偿通过”。排除遮挡/显露，内部与轮廓分开；
  报静态基线、有效对数、重复率、残差 P95/P99、>2/255 跳变率和细节保留。
  无随机类别大块切换，修正不得靠关闭纹理或全屏模糊。
* 媒体：枚举实际 UI 波段和正式/legacy 状态；每个可运行波段七种要求案例；
  15–30 秒有效连续 MP4、PNG、配置、哈希、帧索引；原回放完整保留，裁剪单列。
  production / diagnostics 分目录；图库离线；实际浮点数据随包交付。
* 性能：同板 Mali、同输入、预热后 60–120 秒 A/B；render/new/out/display >=60 FPS，
  端到端 <=80 ms，记录 P95/P99、队列/lag/丢帧。58/59 记 FAIL；诊断读回不参与性能。
* 构建与回归：Windows Release/x64 v140、AArch64；核对 EXE/ELF/资源/配置，
  保存回滚；UI INIT/RESET、编号(x,y)、DDS、原输入与 models 字节完整性。

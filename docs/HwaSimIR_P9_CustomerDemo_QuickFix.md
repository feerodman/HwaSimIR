## 1. 最终结果

**STOP 接收到实际开始处理为 0.176750 ms，界面显示 0.177 ms，小于 10 ms。** 独立控制服务真正建立 STOP 排空屏障后记录开始时刻，渲染线程继续负责安全排空和结束。排空阶段另计 **37.443 ms**，不再混入响应值，也没有对显示数值限幅。

| 指令 | 接收→开始执行 | 等效 Hz |
|---|---:|---:|
| RESET | 0.256959 ms | 3891.671434 |
| START | 3.272209 ms | 305.603951 |
| STOP | 0.176750 ms | 5657.708628 |

等效 Hz 是响应耗时的倒数，不是命令处理吞吐量。上述是本次实测结果，不是任意负载下的硬实时保证。低于 1 μs 保守分辨率或无效时间差不产生巨大数字。

最终普通启动 60 秒测试：实际输入 **59.99984 Hz**，首个 60 秒窗口收到 **3597 张新图，即 59.95 FPS**；未排除启动时间。UI 操作结束附近仍有输入，整轮实际数量为 **3612**，不是人为填写 3600。

## 2. 实施内容

- 视频以实际解码 QImage 尺寸计算 `min(1, 1024/W, 1024/H, 可用物理宽/W, 可用物理高/H)`。每帧与窗口布局共用适配路径，只缩小；先保留物理像素数据，再设置 pixmap DPR。左右等宽、居中、编码尺寸和原始标注坐标未变。
- 本地测试覆盖 640×480、800×800、1024×1024、1280×1024、受限窗口以及尺寸切换。800 像素在 DPR=2 时保留 800 像素采样、占 400 逻辑像素，未先降到逻辑尺寸再放大。
- Control 在实际 DDS 类型回调第一处记录接收单调时间并随命令传递；RESET/START 在业务开始处记录执行时间。普通运行 STOP 在现有独立控制服务中启动排空操作，渲染线程执行后续 FIFO 排空。此前排队的 INIT/Control 保留顺序处理入口。没有删除排空保护、改 Latest 或丢弃输入。
- 现有独立诊断通路新增版本 3 / kind 4 的 Control 记录，保留 V2 原布局、CommonData/V1 业务定义。新 Control 才更新最近结果；RESET 清理、INIT、每秒统计和视频不会清除它。STOP 无视频仍发诊断；新生产进程身份避免沿用旧结果。
- 核实协议波段值 1 为 NIR，用户界面统一为“近红外（NIR）”。保留 `default_NVG.json` 兼容文件名及 Auto 默认、MWIR Game 默认。
- 发送器默认输入按应用目录解析，缺失明确失败。实际初始化表单、构造值、DDS 回读和接收显示一致；补正原启动摘要中未跟随表单的旧值。压缩 NIR 字段附近布局留足完整名称，保留平台 2 行、目标 7 行。

关键源码：`DDS/Runtime/{RuntimeTelemetryV2.h,BoardTelemetryService.h,StopDrainOperation.h}`、`HwaSimIR.cpp/.h`、`VideoPixelFit.h`、VideoDisplay 与 `DdsVideoReceiverWorker.cpp`、`P7ReceiverLayout.inl`、发送器 `mainwindow.cpp` / `p7_sensor_form.inl`。测试、取证和打包入口为 `tools/p9_*`。

## 5. 撤销的试验与保留限制

首次 STOP 为 38.302837 ms，混入既有排空等待。先把开始与结束分开后仍实测 15.951252 ms，主要还等主渲染执行入口；因此没有仅改标签宣称通过，最终让控制服务实际启动 STOP 排空状态机。三个版本的计时证据均保留。

原演示云原点东经 116° 与指定轨迹附近东经 100° 不一致，公共切平面高度偏差导致云不进入期望视场；仅在独立演示天气中纠正静态原点。随后 seed=12345 仍未使体积云与轨迹相交，改为固定 seed=30。近景 16 步版本出现回压、P99 约 322.682 ms；最终仅演示质量配置调整为近 12、中 10 步后，回压为 0。未保留无效原点/seed/采样试验为正式默认。

保留 P8 限制：视频延时尖峰、近云偏软与代理遮挡近似、真实模型语义未标定。本轮没有复测十分钟雨雪矩阵、真实 4K、全部异步/重连边界或传感器实验，不把短测当作这些项目重新认证。

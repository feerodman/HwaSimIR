## 三、尾焰：从“有正贡献”改成“形态连续、合成正确、运动稳定”

先审查当前 32 个 quad、周期 age/fract、半径包络、core/halo 两层及固定 bin 的实际表现。检查喷口位置/方向/米制尺寸、模型缩放、双发偏移、billboard 朝向、alpha/atlas 通道、atlas mip 串色、LOD 和 shader 扩张后的包围体。建立“profile 参数→CPU 计算→uniform→最终 shader 使用”表，特别核对 axialDecay/radialDecay/noise 等参数是否真正生效。

用当前用户模型同一场景，隔离 core、halo、mask、层数/粒子数、排序、固定映射和正常映射，解释白块、梳齿、片状边缘及可能的大片饱和分别从哪里产生。不能只增加粒子数、整体模糊或降低灰度就宣称修复。

允许局部重构表现几何，不要求死守 32 片方案。优先比较低开销的连续局部包络/少量切片/解析密度与现有软粒子，选一种适合 RK3588 的实现。热核心应连续，外层允许扩散、冷却和自然不规则变化；不能有矩形卡片轮廓、规则梳齿、断层或整团突然翻转。尾部外形由密度、温度和投影共同形成，不为“好看”强制所有场景为同一三角形。

热核心、热气体外层、冷烟的含义必须明确。固定 halo70/core71 可以保留为受控近似，但必须核验侧视、斜后视、正后视，以及与目标/云交叠时的遮挡和合成；不能把固定顺序当作任意视角的正确体积积分。

检查绝对辐亮度与相对背景增量的契约，尤其确认 profile 的 B(T)-B(Tambient) 是否被当作绝对 source function 使用；这是待核查风险，不预设已犯错。对均匀介质的合成，应能解释 L_out = T*L_in + (1-T)*S。明确覆盖率、光学厚度、源函数、band emissivity、大气透过率和 path radiance 的作用位置，避免重复乘 alpha、重复传播，或在多层叠加中漏计/重复 path。

补一个通用均匀介质测试：相同源函数与总光学厚度拆为不同层数/粒子数后，输出应在预先记录的数值容差内一致；等温平衡背景不应凭空出现亮暗变化。冷热贡献的符号由源函数和背景决定，不能为了报告“热核心为正”固定绘制颜色。

保持辐射值与显示值分离。允许修复不合理的每波段显示窗口/AGC 配置，但必须单独提交并记录，不能用 tau=1、任意增益、强制白色、整机升温遮掩问题。A/B 使用同波段相同映射，不逐图自动拉伸。

验证发动机开/关/恢复、近中远投影尺寸、相机侧转和目标转动。噪声/粒子相位使用连续仿真时间和稳定种子，不使用每帧重新随机或低精度 epoch。需要保留的烟迹不能随目标旋转一起刚性摆动；不需要长历史轨迹的局部热气体应明确近似边界。

## 四、天气：重审空间分布、辐射来源和可见性，不只是换纹理

把现有世界云、云纹理、降水 Batch、天气状态和 Stage6 显示的调用链梳理成一张表。区分：没提交 draw、实际不在视线内、光学厚度很低、介质与背景辐射接近、短波源函数缺项、8-bit 映射压缩、以及编码损失。不能只凭 raw 非零宣布天气效果合格。

云保持世界空间逻辑，不退回相机前固定 Card。验证云下仰视、云上俯视、视线穿云和转向时的视差；检查地理/世界坐标、云底/云顶高度、相机位置、可见体积预算及物体遮挡。解决明显的重复瓦片、切片、包围盒轮廓、边缘截断和云体切换闪变。不得强制所有高度、方向都能看见云。

雨雪要检查现有相机附着节点及视锥粒子池是否造成贴屏、随 FOV 重排或方向跳变。相机附近循环粒子池可以作为有限范围工程近似，但空间锚定、风/重力方向、相机运动、循环边界和高度限制必须自洽。不能在相机高于有效降水区时仍向镜头贴雨雪。

雨丝长度和覆盖率应审查相对速度、曝光时间及像素足迹的关系；核查现有硬编码长度倍率和 0.72 像素宽度下限。亚像素变宽若改变了覆盖面积，应有相应覆盖率/光学厚度处理，不能只声称“没有调增益”。雪的尺度、速度和漂移应与雨有可辨区别，不能仅把同一批粒子换图。

按波段核对介质源函数及其已有数据来源。特别查 NIR/SWIR 日间是否遗漏已支持的照明/散射来源，不能仅拿低温 Planck 项表示全部天气外观；MWIR/LWIR 也不能一律画白色雨雪。复用已有物理/工程代理接口，缺少数据时声明支持边界和假设，不杜撰系数或扩大 MODTRAN 域。

合理低对比的物理条件允许存在。要另外选取位于既有支持域、视线确实经过天气体积的代表场景，证明 Clear、Cloudy、Overcast、Rain、Snow 在普通输出中有合理区别；不能通过修改原 1.txt、强制 tau、逐效果调亮或屏幕蒙版制造区别。

## 五、模型纹理闪烁：建立编码前的因果证据，修根因

P16 已添加颜色 mipmap/三线性/各向异性，以及材质 ID 众数 mip。本轮不能再次仅调用这些设置就宣布解决。

P16 的 11.18% 来自解码 H.264 的相邻前景 MAD，脚本未做运动补偿；交付 comparison.json 的 parallax_texture 为 360 帧、修改前后分别 26/27 个 uniqueDecodedFrames。不能直接据此认定造假或渲染只有该帧率，但必须解释运动采样、合法重复画面与输出帧的关系，避免大量零差样本稀释指标。

用同一次普通入口运行的 generation/sourceSeq/renderSeq/时间戳，对齐以下层次：材料/辐射原始输出、Stage6 后编码前图像、接收解码帧、Qt 呈现。诊断期可保存短连续 raw ROI 和少量全帧浮点数据；不必长时间逐帧导出全画面浮点图，诊断开销与性能验收分开。

构造最少但可区分原因的实验：
1. 固定相机和目标，固定温度/照明/时间相关状态，关闭噪声并锁映射，测静态数值基线。
2. 固定相机，仅目标慢速平移，包含亚像素移动；再单独旋转目标。
3. 固定目标，仅移动相机/FOV，检查采样和 LOD 阈值。
4. 相同场景分别输出纯几何、颜色纹理、材质 ID/覆盖率、正式辐射，并比较编码前后。
5. 恢复普通输入、天气/尾焰和正常显示，回归实际使用。

逐项确认/排除：高频纹理/法线与镜面 aliasing；材质 ID 或 mip/LOD 阶跃；重复面/z-fighting/透明表面；UV/导数与 atlas 边缘；大坐标 float 精度/深度精度；uniform/温度/辐射低频更新相对 60Hz 姿态的错位；AGC 跳变；缓冲复用和线程同步；编码或 Qt 呈现。Qt paint 长尾与纹理闪烁分别建项，没有证据不要混为一谈。

材质 ID 不得直接线性插值成另一种编号。若证实 nearest_mipmap_nearest 或众数 mip 的类别跳变是根因，可采用按像素足迹的材料覆盖率/权重预滤波，对各材料计算后的辐亮度进行积分；不要平均 ID，也不要把温度简单平均后当成等价辐射。只对证据指向的分支实施，不无条件大改整个材料系统。

关闭条件不再是“平均 MAD 降了一点”。对纯平移诊断做已知几何运动补偿；一般场景使用可靠重投影并排除遮挡/显露区，分别统计模型内部和轮廓。报告静态噪声基线、有效运动样本、重复画面比例、残差 P95/P99、异常跳变率，并保留空间细节/轮廓质量检查。必要时以少量离线高采样帧为参考。

修复后普通运动片段应无明显随机纹理跳闪、类别大块切换和整机忽明忽暗；不能靠关闭纹理、冻结物理更新、降低分辨率、重度全屏模糊或强历史混合掩盖。远距仅数像素目标的正常像素覆盖变化，应与真正时序错误区分。

## 七、构建、板端性能和回归

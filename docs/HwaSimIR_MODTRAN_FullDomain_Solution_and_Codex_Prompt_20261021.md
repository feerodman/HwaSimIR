### 1. 能承诺的“通用”能力

首版建议使用项目已有的标准环境：Mid-Latitude Summer、Rural，按原有地表湿度缩放语义支持 RH30–85、能见度 6–23 km。它可以接受任意经纬度，再从位置、日期和时间计算真实几何与太阳状态；它不是当地实时天气数据库。

当前 `scaled_mls_surface_rh85` 的含义是以 MLS 地表参考湿度缩放水汽廓线，并设置相应气溶胶湿度，不代表 20 km 高度局地湿度也是 85%。如果客户字段表示的是高空局地测量湿度，必须先明确转换契约。

两端高度各为 3–20 km，距离 0–50 km，表示**物理可实现组合**。例如两端高度差 17 km、斜距 1 km 不存在。经纬高、海拔基准、直线斜距与 MODTRAN 路径输入的约定应统一。全局最小值和最大值不能替代有效插值单元。

0 km 是传播极限：透过率为 1，路径热辐射和路径散射为 0；目标发射与目标处照明仍然存在。相机与目标重合时观察方向无定义，需要独立处理。正的近距离不能全部钳制为 0、100 m 或旧表最小距离。

### 2. 数据按物理分量组织

| 数据族 | 核心输入 | 输出与用途 |
|---|---|---|
| LOS 传播 | 传感器高度、目标高度、合法路径、大气状态、波段 | `tau`、路径热辐射；固定温度与成分廓线下不重复乘太阳维度 |
| 目标处照明 | 目标高度、大气状态、太阳条件 | 成像波段直射与半球漫射辐照度 |
| 宽带加热 | 目标高度、大气状态、太阳条件 | 既有 0.30–2.50 μm 积分，W/m²，进入有热惯性的材质模型 |
| 太阳路径散射 | LOS、大气状态、太阳天顶、太阳与视线相对方位 | 散射路径辐亮度 |
| 天空与地面背景 | 观察者高度、相机方向、背景交点、大气与太阳状态 | 独立背景辐亮度与照明，不依赖目标是否存在 |

实现可以保留现有文件作为兼容入口，也可以使用版本化分表；不要求盲目重写全部渲染架构。生成时应去重；运行时也不应复制大量不依赖观察高度和距离的目标照明值。

天空方向辐亮度与半球天空辐照度不是同一个量。背景地面可能在海拔 0 km，天空路径可能到大气顶，近地平线路径可能超过 50 km。因此背景域应独立于空中目标域设计。

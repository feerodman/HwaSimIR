1. 不含云的背景；

## 4. 必须完成的最小对照，不是一开始就调云亮度

每次只改变一项，其他输入固定：

- 保留实际密度，暂将 `artLight=1`：判断源图 G 通道/人工明暗曲线的影响。
- 使用均匀密度、固定源色：判断积分/边界/透明合成的影响。
- 关闭片状云但不改变体积云身份：判断层间重叠与局部片层淡出。
- 一朵云与两朵云：判断透明顺序、双重绘制或遮挡。
- 现有 8/10 步与 16/32/64 步同帧参考：判断采样误差；高步数仅用于诊断，不直接设为生产默认。
- 固定显示、冻结 Auto 与动态 Auto：判断显示是否只是放大已有结构。
- 编码前与解码后：判断 H.264 误差是否只是次要因素。

高步数参考必须核实 shader 循环上限和 uniform 实际值，禁止配置写了 64、实际仍只执行 8 步。64 步是收敛参考，不称为绝对真值；简单均匀场另用解析式验证。

输出 `cause_matrix.csv`，记录改动项、暗纹是否仍存在、线性最小/最大值、局部差异、实际耗时、证据文件。

## 5. 通用透明合成正确性

先用已知数值的普通测试图验证，不涉及目标热参数。

### 5.1 明确 alpha 语义

对同一条图层路径只选择并声明一种：

- 颜色未预乘透明度；或
- 颜色已预乘透明度。

shader 输出与固定管线混合因子必须配套。不把已乘透明度的颜色再乘一次；也不把未乘透明度的颜色当成已经预乘。

同时检查：

- 积分得到的累计颜色是否再次重复衰减；
- 最终 alpha 被限幅时，累计颜色与归一化分母是否仍一致；
- 颜色是否在公共显示之前被独立、不同地裁到 0–1；
- 云的近远排序、同一代理前后面是否重复合成；
- 半透明层是否错误写深度。

当前代码包含前/背面 discard，不能仅看到双面节点就断言重复绘制；须由实际计数或受控对照证明。

### 5.2 人工恒定合成测试

定义合成规则：

`C_out = (1-alpha)*C_background + alpha*C_source`

至少验证：

- 背景 0.2、源值 0.8、alpha=0.5，显示前应为 0.5；
- 背景与源值都为 0.4，改变有效 alpha 不改变结果；
- 密度为零时与无云背景一致；
- 零 opacity 与关闭图层一致；
- 有效 alpha 为 0、0.25、0.5、0.95 的序列；
- 同源色的两层拆分与等价总透明度一致；
- 不同源色两层按明确前后顺序与 CPU 参考一致；
- 所有中间结果有限，透明度在定义区间。

这些测试使用常量源、冻结映射，不对具有空间明暗的艺术云强加“所有像素都必须比背景亮”的判据。浮点容差按实际 RGB16F 精度声明；DDS 有损误差另列，不要求压缩后逐字节相等。

修复时优先最小变更，不把一般 alpha 缺陷升级成整套新的光照框架。

## 6. 云形、暗纹与偏软：正确性之后才调整外观

修复合成缺陷后，再处理被证实的素材和采样问题。

### 6.1 2D 素材与派生体数据

分别检查源 PNG 的亮度、alpha 及派生体的 R/G 切片和投影。确认背景灰、预画阴影或透明边缘数据有没有被复制成贯穿体积的固定黑片。

密度负责形状/遮蔽；人工明暗负责外观。不要将同一来源无说明地重复作为密度、阴影和透明度乘算。

如果问题来自素材明暗的直接挤出：调整派生构建或明确的艺术明暗映射，保留原图、旧缓存和同帧对照。新参数放天气预设，不散落到目标代码。

允许改进美术源值和空间层次，但必须说明它们是游戏外观。不能通过整场 gamma、黑位抬升、提高全部云不透明度来消灭暗纹。

### 6.2 采样与帧率

根据投影大小和沿视线的有效密度范围选择局部质量档，减少空区域采样，避免机械地增加全部云的分辨率和采样数。

本轮默认双云；四云不作为必须通过项。保持 800×800、DDS、MPP 和同步关系。

不采用全屏模糊掩盖条带，不通过减少到单云或移开相机回避问题。生产档与高步数参考需要同构图对照。

### 6.3 遮挡的边界如实记录

保持 P4/P5 原生深度路径，禁止未经板端验证恢复自动深度附件替换或失败的深度复制。

本轮验证云前/云后的普通不透明平板；云内物体若仍只有代理深度近似，必须作为限制保留。不能把外部遮挡通过宣传为全地形阴影或完整体积深度截断通过。

## 7. 画质验收必须是有限、可检查的任务

实际交付以下六类场景，NIR/NVG 与 MWIR 分别使用发布默认显示：

1. 单云中景，固定相机；
2. 近景云边，缓慢横移；
3. 两云分离；
4. 两云部分重叠；
5. 片云与局部双云同屏；
6. 普通平板在云前/云后，以及相机接近或进入云代理的边界测试。

每组保存无标注编码前图、实际接收图和短视频；有故障的位置另保存局部放大图。局部图只能裁切/明确缩放，不进行对比度增强后冒充原图。

判断重点：

- 黑条是可解释的素材/遮蔽结构，还是错误合成/采样结构；
- 镜头移动时是否出现平行条带、突然反色、接缝或轮廓断裂；
- 云是否仍有内部疏密，避免变成统一白色棉团或均匀灰雾；
- Auto 是否只呈现源图变化，而非用新的参数压住故障；
- 图像外观的改善是否在正常运行和正式相机配置中生效。

不承诺仅凭数值指标达到参考软件所有艺术质量。代码修复通过、指定场景外观通过、其他视角限制分别写清楚；不能把“全部云必须白”作为标准。

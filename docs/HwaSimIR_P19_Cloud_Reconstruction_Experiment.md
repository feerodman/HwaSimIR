# P19 云绘制重建实验

状态：候选25构建和板端对照进行中。稳定DDS24包保留，尚未接受视觉变化或宣布性能通过。

## 修改边界

`HwaCloudPresentationDivisor=1` 为默认原分辨率路径；2、4分别把白色云外观附件的长宽除以2、4。最终320/800视频尺寸不变，物理SI云附件、云密度纹理、采样步数、尾焰、雨雪、HDR和对数深度不变。层云、团云使用同一世界几何。低分辨率云射线按比例访问原始全分辨率不透明深度；最终合成用四邻域深度权重重建，避免跨越机体遮挡边缘直接线性插值。无历史帧重用，不丢帧。

这会改变云外观层的像素采样，不能预先宣称效果完全不变。需检查云细节、轮廓、薄目标遮挡和运动；误差均值低也不等于视觉合格。

## 预定验证

1. Windows和ARM构建；板端GLSL编译、运行无错误。
2. 同一600帧offset3000重云轨迹，双路raw，分别divisor1、2、4；同源输入、全帧收发、每帧误差及真实FPS/STOP排空。
3. 提取差异较大帧和连续片段，检查遮挡/轮廓；若候选有足够提升，再做3600帧双路正常编码长测。
4. 默认路径有回归或视觉不可接受时，恢复DDS24稳定版本；实验和失败证据保留。

## 源码

- `IR/IRCloudPresentation.inl`：云附件尺寸、深度坐标映射、启动日志。
- `HwaSimIR.cpp`：最终四邻域深度重建和体积云深度坐标。
- `HwaSimIR.h`：独立云分辨率状态。

未知客户硬件和屏幕呈现延迟仍不由这些实验验证。性能端点为同Windows时钟的激励到解码图像。

## 候选25实测（双路、600帧/路、offset3000）

| 路径 | 精跟FPS | STOP ms | 最大输入积压 | 功能 |
|---|---:|---:|---:|---|
| 稳定24原路径 | 39.71 | 5156.343 | 212 | PASS |
| 25半分辨率云 | 46.82 | 2864.574 | 138 | PASS |
| 25四分之一分辨率云 | 50.45 | 1944.029 | 100 | PASS |

两种低分辨率方案仍有持续积压，性能目标FAIL；半分辨率整帧MAE约0.298、四分之一约0.338，局部最大误差96/95灰度。最大误差集中在小目标附近，低分辨率深度可能漏过薄目标，不能仅凭平均误差接受。

候选26正在补目标区域的全分辨率云积分：背景使用重建，实际不透明几何所在像素使用原尺寸云射线、原裁剪和原采样数。这样保留目标前云的衰减，不以删除目标区域的云来遮掩误差。该路径也有额外绘制成本，需实测。

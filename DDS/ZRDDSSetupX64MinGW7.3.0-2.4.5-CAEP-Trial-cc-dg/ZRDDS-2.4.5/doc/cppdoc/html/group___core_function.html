DDS_Long ZRGetNowTimeString ( DDS_Char *  strformat)

获取日历时间的字符串形式. 格式"1970-01-01 00:00:00:000"。

参数
[in,out]strformat字符串缓冲区用来存储结果，需要保证有足够的空间。
前置条件
strformat为64字节以上的空间。
返回
返回距离1970/1/1 00:00:00的毫秒数.

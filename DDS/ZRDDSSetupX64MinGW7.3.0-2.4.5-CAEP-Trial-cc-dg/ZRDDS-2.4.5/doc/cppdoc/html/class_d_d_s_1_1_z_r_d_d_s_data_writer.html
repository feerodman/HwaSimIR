详细描述

template<typename T>
class DDS::ZRDDSDataWriter< T >

ZRDDS提供的数据写者模板类，用于提供强类型安全接口的数据写者接口。

模板参数
T用户定义数据类型，例如： Foo

模板参数T为用户定义数据类型，本模板仅定义数据写者中与主题关联的数据类型相关的接口， 其余与类型无关的接口直接使用父类 DDS::DataWriter 的即可。

示例:
ExtendInterface/app1.cpp, ExtendInterface/app3.cpp, SecurityExample/ac_example_pub.cpp, SecurityExample/auth_example_pub.cpp, SecurityExample/encry_example_pub.cpp, SimpleInterface/SimpleInterfaceBytesTypePub.cpp, SimpleInterface/SimpleInterfaceZeroCopyPub.cpp, SimpleInterface/SimpleInterfaceZeroCopySub.cpp, TCPConcurrentTransmission/SimpleInterfaceBytesTypePub.cpp, TCPConcurrentTransmission/SimpleInterfaceZeroCopyPub.cpp, TCPConcurrentTransmission/SimpleInterfaceZeroCopySub.cpp , 以及 UDPLargePackageZeroCopy/SimpleInterfaceBytesTypePub.cpp.

template<typename T >
InstanceHandle_t DDS::ZRDDSDataWriter< T >::register_instance ( const T &  data)

向数据写者注册一个实例

当数据类型T中带有键域声明的成员时，成员的取值不同会形成不同的实例， 该接口向数据写者注册一个实例，数据写者会读取传入的 data 中声明为键域的数据域， 根据其值生成一个实例句柄并返回给用户。实例句柄用于索引实例，如 write 操作中的 handle 参数。 当 DDS_DataWriterResourceLimitsQosPolicy::autoregister_instances == true 时， 且调用 write 接口时 handle 参数传入 DDS_HANDLE_NIL_NATIVE 时，会自动注册未注册的实例， 但是发送速度会减慢，因此可使用先注册的实例句柄提升发送的速度。

参数
data样本内容，只有被声明为键域的成员会被读取。
返回
如果注册成功，返回样本对应的实例句柄，否则返回 DDS_HANDLE_NIL_NATIVE

template<typename T >
ReturnCode_t DDS::ZRDDSDataWriter< T >::write ( const T &  data,
const InstanceHandle_t &  handle 
)

发布一个数据样本。

该接口可能发生阻塞：当设置为可靠传输，且该数据写者历史数据配置 DDS_HistoryQosPolicy::kind == DDS_KEEP_ALL_HISTORY_QOS 时，若样本超出限制时会发生阻塞， 当使用同步发送且调用协议栈接口出现阻塞时会发生阻塞， 若因样本超出限制导致阻塞，最长阻塞时间通过 DDS_ReliabilityQosPolicy::max_blocking_time 配置， 因协议栈导致的阻塞最长阻塞时间不可预知

参数
data需要发布的数据样本。
handle数据样本对应的实例句柄，当该数据写者资源限制配置 DDS_DataWriterResourceLimitsQosPolicy::autoregister_instances == true时， 可以传入 DDS_HANDLE_NIL_NATIVE ，此时底层将自动注册 data 所属数据实例。
返回
当前可能的返回值如下：
  • DDS_RETCODE_OK :表示获取成功；
  • DDS_RETCODE_NOT_ENABLED :表示实体未使能；
  • DDS_RETCODE_BAD_PARAMETER :参数中存在错误；
  • DDS_RETCODE_OUT_OF_RESOURCES :当前资源不足；
  • DDS_RETCODE_TIMEOUT :当前操作超时；
  • DDS_RETCODE_ERROR :表示未知错误导致的读取错误。
示例:
SecurityExample/ac_example_pub.cpp, SecurityExample/auth_example_pub.cpp , 以及 SecurityExample/encry_example_pub.cpp.

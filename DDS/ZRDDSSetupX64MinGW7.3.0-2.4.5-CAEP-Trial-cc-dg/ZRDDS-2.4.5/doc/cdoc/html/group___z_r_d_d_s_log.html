format字符串格式(类printf).
...变参。
#define ZRLOG_DEBUG_W_EXP2 (   guid,

  postState2,
  format,
  ... 
)
值:
ZRLOG_PRINT_MESSAGE(format, debugNo); \
if (ZRLogVerifyDebugCondition(debugNo, topic, guid)) \
{ \

postState1; \
postState2; \
ZRLogEndLog(); \
}

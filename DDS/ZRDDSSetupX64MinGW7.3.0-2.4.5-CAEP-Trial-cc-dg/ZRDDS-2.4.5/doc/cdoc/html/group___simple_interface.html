函数说明

DCPSDLL DDS_Long DDS_BytesWrapper ( DDS_Bytes *  self,
const DDS_Char *  buffer,
const DDS_Long  length 
)

用户缓冲区包装成DDS_Bytes类型（非零拷贝缓冲区数据类型），该接口不分配空间，无需对应的回收函数。

参数
[in,out]self指明包装的目标。
buffer用户提供空间。
length空间长度。
返回
0表示成功，否则表示失败。
DCPSDLL DDS_ReturnCode_t DDS_BytesWrite ( DDS_DomainId_t  domainId,
DDS_Char *  topicName,
const DDS_Char *  content,
const DDS_Long  length 
)

向指定的域发送指定主题的非零拷贝Bytes数据。使用该接口的前提：

  • 指定的域内有且仅有一个域参与者；
  • 指定的域内有且仅有一个与指定主题关联的发布者；
  • 指定的主题关联的数据类型为DDS_Bytes数据类型； 如果不满足以上条件，请使用 DDS_BytesDataWriter_write 接口指定发布者发送数据。
参数
domainId指明域号。
[in,out]topicName指明主题名称。
content发送内容缓冲区。
length缓冲区长度。
返回
DDS_RETCODE_OK 表示发送成功， 其他表示失败。
示例:
SimpleInterface/SimpleInterfaceBytesTypePub.c, TCPConcurrentTransmission/SimpleInterfaceBytesTypePub.c , 以及 UDPLargePackageZeroCopy/SimpleInterfaceBytesTypePub.c.
DCPSDLL DDS_DomainParticipant * DDS_CreateDP ( const DDS_DomainId_t  domainId,
const DDS_Char *  qos_name 
)

DDS创建域参与者，并指明域号与QoS配置名称，同一个域号可能有多个域参与者， 需要为使用不同底层传输协议的主题创建不同的域参与者，即通常SRIO、UDP、TCP的域参与者各一个。

参数
domainId指明域号，域号范围0-232
qos_name指明QoS配置文件中域参与者QoS配置名称，允许为NULL，表明使用配置文件中名称为default的配置。
返回
NULL表示失败，否则返回域参与者的指针，该指针用于后续创建发布者以及订阅者。
示例:
SecurityExample/ac_example_pub.c, SecurityExample/ac_example_sub.c, SecurityExample/auth_example_pub.c, SecurityExample/auth_example_sub.c, SecurityExample/encry_example_pub.c, SecurityExample/encry_example_sub.c, SimpleInterface/SimpleInterfaceBytesTypePub.c, SimpleInterface/SimpleInterfaceBytesTypeSub.c, SimpleInterface/SimpleInterfaceZeroCopyPub.c, SimpleInterface/SimpleInterfaceZeroCopySub.c, TCPConcurrentTransmission/SimpleInterfaceBytesTypePub.c, TCPConcurrentTransmission/SimpleInterfaceBytesTypeSub.c, TCPConcurrentTransmission/SimpleInterfaceZeroCopyPub.c, TCPConcurrentTransmission/SimpleInterfaceZeroCopySub.c, UDPLargePackageZeroCopy/SimpleInterfaceBytesTypePub.c , 以及 UDPLargePackageZeroCopy/SimpleInterfaceBytesTypeSub.c.

DCPSDLL DDS_DomainParticipantFactory * DDS_Init ( const DDS_Char *  qosFilePath,
const DDS_Char *  qosName 
)

以指定配置初始化DDS中间件，只在整个程序初始化时调用一次即可。

参数
qosFilePathQoS配置文件的路径，可以是绝对路径，也可以是程序运行目录的相对路径， 为NULL时，默认使用运行目录的 ZRDDS_QOS_PROFILES.xml 配置文件。
qosNameQoS配置文件中工厂QoS配置名称，DDS将以 default_lib::default_profile::qosName 代表的QoS初始化DDS域厂， 允许为NULL，表明使用配置文件中名称为default的配置。
返回
NULL表示失败，否则返回DDS域工厂单例。
示例:
SecurityExample/ac_example_pub.c, SecurityExample/ac_example_sub.c, SecurityExample/auth_example_pub.c, SecurityExample/auth_example_sub.c, SecurityExample/encry_example_pub.c, SecurityExample/encry_example_sub.c, SimpleInterface/SimpleInterfaceBytesTypePub.c, SimpleInterface/SimpleInterfaceBytesTypeSub.c, SimpleInterface/SimpleInterfaceZeroCopyPub.c, SimpleInterface/SimpleInterfaceZeroCopySub.c, TCPConcurrentTransmission/SimpleInterfaceBytesTypePub.c, TCPConcurrentTransmission/SimpleInterfaceBytesTypeSub.c, TCPConcurrentTransmission/SimpleInterfaceZeroCopyPub.c, TCPConcurrentTransmission/SimpleInterfaceZeroCopySub.c, UDPLargePackageZeroCopy/SimpleInterfaceBytesTypePub.c , 以及 UDPLargePackageZeroCopy/SimpleInterfaceBytesTypeSub.c.
DCPSDLL DDS_DataWriter * DDS_PubTopic ( DDS_DomainParticipant *  self,
const DDS_Char *  topicName,
DDS_TypeSupport *  typeSupport,
const DDS_Char *  qos_name,
DDS_DataWriterListener *  dwListener 
)

发布主题，指定域参与者、主题名、类型名、QoS配置名称以及监听器。

参数
[in,out]self指明域参与者。
topicName主题名称。
[in,out]typeSupport类型支持对象指明关联的数据类型，规则为： &类型名称+TypeSupport+_instance, 如果为零拷贝数据类型则传输 &DDS_ZeroCopyBytesTypeSupport_instance， 内置非零拷贝传入 &DDS_BytesTypeSupport_instance，IDL文件自动生成的传入 & 类型名称TypeSupport_instance对象。
qos_name指明QoS配置文件中数据写者QoS配置名称，允许为NULL，表明使用配置文件中名称为default的配置。
[in,out]dwListener发布者的监听器，用于扩展，填NULL即可。
返回
NULL表示失败，否则返回数据写者指针（用于唯一标识创建好的发布者）。
示例:
SecurityExample/ac_example_pub.c, SecurityExample/auth_example_pub.c, SecurityExample/encry_example_pub.c, SimpleInterface/SimpleInterfaceBytesTypePub.c, SimpleInterface/SimpleInterfaceZeroCopyPub.c, TCPConcurrentTransmission/SimpleInterfaceBytesTypePub.c, TCPConcurrentTransmission/SimpleInterfaceZeroCopyPub.c , 以及 UDPLargePackageZeroCopy/SimpleInterfaceBytesTypePub.c.

DCPSDLL DDS_ReturnCode_t DDS_ZeroCopyBytesWrite ( DDS_DomainId_t  domainId,
DDS_Char *  topicName,

)

向指定的域发送指定主题的零拷贝数据。使用该接口的前提：

  • 指定的域内有且仅有一个域参与者；

# HwaSimIR 简单 DDS 控制发送端

## 工程用途

本 Demo 提供最小的 ZRDDS typed data 接口，用于发送 `Control / Init / Realtime` 和等待 `InitAck`。它不生成测试数据、不包含测试流程，也不负责视频 DDS。

## 文件

- `main.cpp`：最小可执行入口，不包含测试参数或测试数据。
- `HwaSimIRSimpleDdsClient.*`：DDS 初始化、一个 Publisher、三个 typed Writer 和 Ack Reader。
- `../Generated/HwaSimIRProtocolV1/`：`zrddsgen` 生成的 TypeSupport、Reader、Writer。
- `Config/ZRDDS_PROTOCOL_QOS.xml`：`tcpv4://default//0`、RELIABLE、KEEP_ALL 配置。

## Topic

| Topic | Type |
|---|---|
| `HwaSimIR.Control` | `HwaSimIRDds::ControlCommandV1` |
| `HwaSimIR.Init` | `HwaSimIRDds::InitCommandV1` |
| `HwaSimIR.Realtime` | `HwaSimIRDds::RealtimeDataV1` |
| `HwaSimIR.InitAck` | `HwaSimIRDds::InitAckV1` |

## 客户集成步骤

客户工程只需参考或复制：

```text
HwaSimIRSimpleDdsClient.h/.cpp
DDS/Generated/HwaSimIRProtocolV1/
DDS/IDL/HwaSimIRProtocolV1.idl
Config/ZRDDS_PROTOCOL_QOS.xml
```

客户业务代码自行填写 IDL Sample，然后调用以下接口：

```cpp
HwaSimIRSimpleDdsClient client;

client.init(domainId, qosFile);
client.sendControl(control);
client.sendInit(init);
client.waitForInitAck(platID, sensorID, timeoutMs, ack);
client.sendRealtime(realtime);
client.shutdown();
```

`Control` 以 `platID` 为 Key；`Init/Realtime/Ack` 以 `platID + sensorID` 为 Key。一个 Writer 可以连续写多个传感器，因而 `max_instances` 设为 64，不能沿用单灰度实例 Demo 的 `max_instances=1`。

## 与 ShapeType 发布代码对应

| 旧灰度示例 | HwaSimIR typed data |
|---|---|
| `ShapeTypeTypeSupport` | `ControlCommandV1TypeSupport`、`InitCommandV1TypeSupport` 等 |
| `create_topic` | 相同，Topic 绑定对应 TypeSupport |
| `ShapeTypeDataWriter` | `ControlCommandV1DataWriter`、`InitCommandV1DataWriter` 等 |
| `dw->write(...)` | 相同，直接写 IDL Sample |
| `max_instances=1` | HwaSimIR 不可固定为 1，当前为 64 |

## Build（MinGW 7.3.0 x64）

本机已验证路径：

```text
MinGW: D:\Qt\Qt5.12.12\Tools\mingw730_64
ZRDDS: F:\Programs\ZRDDS\ZRDDS_MinGW7.3.0\ZRDDS-2.4.5
```

在 PowerShell 执行：

```powershell
cd D:\HwaSimIR
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DDS\HwaSimIRSimpleDdsSenderDemo\build_mingw.ps1
```

脚本会配置并构建：

```text
D:\HwaSimIR\build-HwaSimIRSimpleDdsSenderDemo-mingw73_64-Release
```

机器已安装 CMake 时，脚本执行等价于：

```powershell
cmake -S . -B D:\HwaSimIR\build-HwaSimIRSimpleDdsSenderDemo-mingw73_64-Release -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_C_COMPILER=D:\Qt\Qt5.12.12\Tools\mingw730_64\bin\gcc.exe -DCMAKE_CXX_COMPILER=D:\Qt\Qt5.12.12\Tools\mingw730_64\bin\g++.exe -DCMAKE_MAKE_PROGRAM=D:\Qt\Qt5.12.12\Tools\mingw730_64\bin\mingw32-make.exe -DZRDDS_ROOT=F:\Programs\ZRDDS\ZRDDS_MinGW7.3.0\ZRDDS-2.4.5
cmake --build D:\HwaSimIR\build-HwaSimIRSimpleDdsSenderDemo-mingw73_64-Release --config Release -- -j4
```

也可用 `-CMakeExe <完整路径>` 指定 CMake。本机未安装 CMake 时，脚本自动执行参数完全等价的 MinGW Release 逐翻译单元编译。

## 说明

生成的 EXE 仅用于确认接口实现能够完整编译和链接，不包含内置运行参数、初始化样例、轨迹数据或自动收发测试。客户应在自己的业务入口中构造 IDL 数据并调用上述接口。

本 Demo 使用 MinGW 版 `ZRDDSCpp.lib/ZRDDSCpp.dll`，禁止链接 `ZRDDSCpp_VS2015.lib`。Trial licence 运行副本必须可写，日志不得打印 licence 正文。

详细描述

ZRDDS提供的订阅者接口，应用创建订阅者表示自身想从指定的域内获取数据；

订阅者主要完成以下几个功能：

  • 实体功能；
  • 作为数据读者的工厂；
  • 统一处理数据读者的数据样本通知；
示例:
CreateDisabledEntity.cpp , 以及 SetBuiltinListenerExample.cpp.

DataReader * DDS::Subscriber::create_datareader ( TopicDescription *  a_topic,
const DataReaderQos &  qoslist,
DataReaderListener *  a_listener,
const StatusKindMask &  mask 
)
pure virtual

该方法在订阅者下创建一个数据读者子实体，并设置关联的主题、QoS以及监听器。

用户使用该数据读者从域内读取/获取指定主题数据，返回的数据读者对象为数据读者关联的用户数据类型相关的数据读者的父类指针， 用户需要将返回值动态转化为用户数据类型的数据读者对象，具体代码参见 subscription_example.cpp 。

参数
[in,out]a_topic关联的主题描述，用户可以关联主题以及基于内容过滤的主题， 该主题描述必须在调用该方法之前在同一个域参与者下调用 DDS::DomainParticipant::create_topic DDS::DomainParticipant::create_contentfilteredtopic 方法创建的主题的父类；
qoslist表示为该数据读者设置的QoS， DDS::DATAREADER_QOS_DEFAULT 表明使用订阅者中保存的默认的QoS。
[in,out]a_listener为该订阅者设置的监听器，此参数可以为空。 ZRDDS不会接管监听器对象的内存管理，由用户负责释放。
mask设置应用程序感兴趣的状态，只有应用程序感兴趣的状态发生变化时，才会通知应用程序。
返回
非NULL表示创建成功，否则表示失败，失败的原因可能为：
  • a_topic 不是有效的主题对象；
  • a_topic 的父实体与该订阅者不属于一个域参与者实体；
  • qoslist 中含有无效的QoS或者含有不一致的QoS配置；
  • 分配内容错误等未归类错误，详细参见日志。

ReturnCode_t DDS::Subscriber::delete_contained_entities ( )
pure virtual

该方法删除该订阅者创建的所有实体。

该方法会对子实体进行递归调用 delete_contained_entities 方法，最终的删除的实体包括数据读者、读取条件等； 该方法采取尽力而为的策略删除，即满足删除条件的实体进行删除，如果有不满足删除条件的实体，则返回特定的错误码。

返回
当前可能的返回值：
  • DDS_RETCODE_OK :表示删除成功；
  • DDS_RETCODE_PRECONDITION_NOT_MET :表示有部分实体不满足删除条件，仅删除部分实体；
  • DDS_RETCODE_ERROR :表示未归类错误，详细参见日志；
ReturnCode_t DDS::Subscriber::delete_datareader ( DataReader *  a_datareader)
pure virtual

删除指定的数据读者。

参数
[in,out]a_datareader指明需要删除的数据读者。

被删除的数据读者应满足删除条件，主要包括：

  • 数据读者创建的所有“子实体”读取条件已经全部被删除；
  • 通过该数据读者的 获取主题数据 系列方法租借给用户的空间已经全部回收成功；
返回
当前可能的返回值如下：
  • DDS_RETCODE_OK ：删除成功；
  • DDS_RETCODE_BAD_PARAMETER ：参数指定的数据读者不是有效的数据读者对象；
  • DDS_RETCODE_PRECONDITION_NOT_MET ：
    • 参数指定的数据读者不属于本；
    • 指定的数据读者不满足删除条件；

ReturnCode_t DDS::Subscriber::get_datareaders ( DataReaderSeq &  datareader,
const SampleStateMask &  sample_states,
const ViewStateMask &  view_states,
const InstanceStateMask &  instance_states 
)
pure virtual

查找底层含有处于特定状态的数据样本的数据读者的结合。

参数
[in,out]datareader出口参数，用于存储满足条件的数据读者列表。
sample_states需要满足的样本状态条件。
view_states需要满足的视图状态条件。
instance_states需要满足的实例状态条件。

可以设置的条件包括 DDS_SampleStateKind 、DDS_ViewStateKind 、 DDS_InstanceStateKind 均通过掩码来表示状态的集合。数据读者中只要有一个样本满足则该数据读者符合条件。

返回
当前可能的返回值如下：
  • DDS_RETCODE_OK ：获取成功；
  • DDS_RETCODE_OUT_OF_RESOURCES ：当datareader 提供的空间不足，且底层扩容失败；
  • DDS_RETCODE_NOT_ENABLED ：本订阅者尚未使能；
  • DDS_RETCODE_ERROR ：内部错误，详细参见日志；

ReturnCode_t DDS::Subscriber::notify_datareaders ( )
pure virtual

本方法将尝试调用所有处于 DDS_DATA_AVAILABLE_STATUS 状态的数据读者关联的监听器的 DDS::DataReaderListener::on_data_available 方法。

当数据读者底层有新的数据到达时，将会处于 DDS_DATA_AVAILABLE_STATUS 状态，当用户回调成功或者用户 通过 获取主题数据 系列方法读取数据时清理这个状态，该方法通常在 DDS::SusbcriberListener::data_on_reader 回调函数中使用。

返回
当前可能的返回值：
  • DDS_RETCODE_OK ：通知成功；
  • DDS_RETCODE_NOT_ENABLED ：本订阅者尚未使能；
  • DDS_RETCODE_ERROR ：内部错误，详细参见日志；
ReturnCode_t DDS::Subscriber::set_default_datareader_qos ( const DataReaderQos &  qoslist)
pure virtual

该方法设置为数据读者保存的默认QoS配置。

默认的QoS在创建新的数据读者时指定QoS参数为 DDS::DATAREADER_QOS_DEFAULT 时使用的QoS配置， 使用特殊的值 DDS::DATAREADER_QOS_DEFAULT 订阅者QoS中的各个配置的设置为默认值。

参数
qoslist指明QoS配置。
返回
当前可能的返回值：
  • DDS_RETCODE_OK :表示设置成功；
  • DDS_RETCODE_BAD_PARAMETER :表示qoslist为空，或者qoslist 具有无效值；
  • DDS_RETCODE_INCONSISTENT :表示qoslist 中具有不相容的配置；
  • DDS_RETCODE_ERROR :表示失败，例如复制QoS时发生错误。

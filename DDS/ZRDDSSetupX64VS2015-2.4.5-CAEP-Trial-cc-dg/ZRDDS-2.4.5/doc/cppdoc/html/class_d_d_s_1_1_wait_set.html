ReturnCode_t DDS::WaitSet::attach_condition ( Condition *  a_condition)

将指定的条件加入到该等待集合中。

如果添加的条件的触发状态为true，将会解开阻塞。

参数
[in,out]a_condition指明需要添加的条件。
返回
当前可能的返回值：
  • DDS_RETCODE_OK :添加成功；
  • DDS_RETCODE_OUT_OF_RESOURCES :分配内存失败；
  • DDS_RETCODE_BAD_PARAMETER :参数不是有效的条件。
示例:
GetPlainStatus.cpp.
ReturnCode_t DDS::WaitSet::detach_condition ( Condition *  a_condition)

从等待集合中移除指定的条件。

参数
[in,out]a_condition指明需要删除的条件。
返回
当前可能的返回值：
  • DDS_RETCODE_OK :添加成功；
  • DDS_RETCODE_PRECONDITION_NOT_MET :指定的条件不在该等待集合中；
  • DDS_RETCODE_BAD_PARAMETER :参数不是有效的条件。

ReturnCode_t DDS::WaitSet::wait ( ConditionSeq &  active_condition,
const Duration_t &  timeout 
)

阻塞等待等待集合中的条件处于触发状态。

应用线程等待某些条件的发生，堵塞调用线程， 当调用成功时，active_condition 中存放触发的条件， 不允许多个线程等待同一个等待条件。

参数
active_condition出口参数，用于存储处于触发状态的条件。
timeout指明最长等待时间。
返回
当前可能的返回值：
  • DDS_RETCODE_OK :出口参数有效，表明处于触发状态的条件；
  • DDS_RETCODE_PRECONDITION_NOT_MET :在多个线程上等待条件；
  • DDS_RETCODE_BAD_PARAMETER / DDS_RETCODE_ERROR ：用户提供的空间不足，且底层扩容失败；
  • DDS_RETCODE_TIMEOUT : 在指定的时间内没有条件处于触发状态。

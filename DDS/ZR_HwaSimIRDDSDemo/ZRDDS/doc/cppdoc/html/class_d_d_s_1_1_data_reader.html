详细描述

DDS标准中的数据读者接口。

数据读者主要负责存储从发布端获取到的数据以及提供接口给上层应用获取接收到的数据，数据读者接口同样包含两类接口：

  • 用户数据类型无关接口，该类即定义了这些与用户类型无关的接口，作为用户类型的数据读者的父类。
  • 用户数据类型相关接口，通过类模板实现， DDS::ZRDDSDataReader
示例:
CreateDisabledEntity.cpp, ExtendInterface/app1.cpp, ExtendInterface/app2.cpp, GetPlainStatus.cpp, SecurityExample/ac_example_sub.cpp, SecurityExample/auth_example_sub.cpp, SecurityExample/encry_example_sub.cpp, SetBuiltinListenerExample.cpp, SimpleInterface/SimpleInterfaceBytesTypeSub.cpp, SimpleInterface/SimpleInterfaceZeroCopySub.cpp, TCPConcurrentTransmission/SimpleInterfaceBytesTypeSub.cpp, TCPConcurrentTransmission/SimpleInterfaceZeroCopySub.cpp , 以及 UDPLargePackageZeroCopy/SimpleInterfaceBytesTypeSub.cpp.

ReturnCode_t DDS::DataReader::delete_readcondition ( ReadCondition *  a_condition)
virtual

删除指定的读取条件。

参数
a_condition指明读取条件。

删除读取条件时，若该条件加入了等待集合中，则将自动从等待集合中删除该条件。

返回
可能返回的值如下：
  • DDS_RETCODE_OK 表示删除成功；
  • DDS_RETCODE_ERROR 表示删除失败，失败的原因可能为：
    • a_condition 不是有效的 DDS::ReadCondition 对象，包括NULL；
    • a_condition 不是由该数据读者创建；

ReturnCode_t DDS::DataReader::wait_for_historical_data ( const Duration_t &  max_wait)
virtual

等待历史数据。

当该数据读者的持久化配置类型 > DDS_VOLATILE_DURABILITY_QOS 时，即该数据读者需要接收在该数据读者 加入网络前，与之匹配的数据写者已经发送的历史数据，调用此函数以等待历史数据接收完成或者超时。

参数
max_wait最长的等待时间。
返回
可能返回的值如下：
  • DDS_RETCODE_OK :表示所有的历史数据均已接收完成，或者不需要接收历史数据；
  • DDS_RETCODE_NOT_ENABLED :表示本数据读者尚未使能；
  • DDS_RETCODE_TIMEOUT :表示在 max_wait 时间内未完成历史数据的接收。

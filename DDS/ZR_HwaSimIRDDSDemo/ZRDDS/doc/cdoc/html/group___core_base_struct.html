详细描述

本模块定义核心接口定义的基础结构体。

类型定义说明

DDS_ULong DDS_DomainId_t

用来表示域参与者所属域的值。

使用无符号整型来表示域参与者所属域的值，在RTPS协议下，由于端口计算方式:不能超过65536，一个域中端口不会 userPort = (7400+250*domainId+2*partId + 11)， builtinPort = (7400+250*domainId+2*partId + 10) 在单独一个节点上，域的取值范围是[0, 232],其中[0, 231]域中有125个Participant，232域中有64个Participant。

DDS_InstanceHandle_t DDS_KeyHash_t

DDS_KeyHash_t 作为当 DDS_InstanceHandle_t 作为数据实例的唯一标识时的别名。

注解
用户不会显式的使用该结构体。
struct DDS_Property

<名称-值>键值对，用来在发现阶段存储节点信息。

现阶段支持的名称有:

  • "dds.sys_info.hostname": 表示DDS程序所在主机名称
  • "dds.sys_info.username": 表示运行DDS程序的用户
  • "dds.sys_info.process_id": 表示DDS程序的进程ID
  • "dds.sys_info.host_ip": 表示DDS程序所在主机IP
  • "dds.sys_info.executable_filepath": 表示DDS程序的可执行程序完整路径

枚举类型说明

enum DDS_InstanceStateKind

此枚举变量列举出一系列的实例状态，与 DDS_InstanceStateMask 结合使用。

实例状态是数据读者为主题中的每个实例关联的一个状态信息，每个样本均包含该状态，参见 DDS_SampleInfo::instance_state 。此状态信息会随着实例的生命周期发生变化而改变。

枚举值
DDS_ALIVE_INSTANCE_STATE 

此状态表示样本所属数据实例处于存活状态。

当数据读者接收到了该数据实例的数据样本后，样本所属的数据实例会转变为此状态，不通知用户。 样本包括两种类型：

  • 包含主题数据的样本，称为数据样本；
  • 不包含主题数据的样本，称为状态样本，其中：
    • 由 DataWriter::unregister_instance 产生注销状态样本；
    • 由 DataWriter::dispose 产生销毁状态样本。
DDS_NOT_ALIVE_DISPOSED_INSTANCE_STATE 

此状态表示样本所属数据实例处于被销毁状态。

当数据读者接收到了销毁状态样本时：

  • 如果原本为 DDS_ALIVE_INSTANCE_STATE 状态样本所属的数据实例会转变为此状态，并通知用户， 用户通过 DataReader::read/take 方法可以获取该事件；
  • 如果原本为 DDS_NOT_ALIVE_DISPOSED_INSTANCE_STATE 状态样本所属的数据实例会转变为此状态，不通知用户。
  • 如果原本为 DDS_NOT_ALIVE_NO_WRITERS_INSTANCE_STATE 状态样本所属的数据实例状态不会改变，不通知用户。
DDS_NOT_ALIVE_NO_WRITERS_INSTANCE_STATE 

此状态表示样本所属数据实例处于被注销状态。

当数据读者接收到了注销状态样本时：

  • 如果原本为 DDS_ALIVE_INSTANCE_STATE 并且此数据写者为最后一个与该数据实例关联的数据写者， 则状态样本所属的数据实例会转变为此状态，并通知用户， 若还有数据写者与该数据实例关联，则不改变状态， 数据写者与数据实例关联是指：数据实例发布过该数据实例下的样本数据，并且最后的样本不是状态样本。
  • 如果原本为 DDS_NOT_ALIVE_DISPOSED_INSTANCE_STATE 状态样本所属的数据实例状态不会改变，不通知用户。
  • 如果原本为 DDS_NOT_ALIVE_NO_WRITERS_INSTANCE_STATE 状态样本所属的数据实例状态不会改变，不通知用户。

enum DDS_SampleRejectedStatusKind

用于标识数据样本被拒绝的原因类型。

枚举值
DDS_NOT_REJECTED 

数据样本未被拒绝。

DDS_REJECTED_BY_INSTANCE_LIMIT 

数据样本由于 DDS_ResourceLimitsQosPolicy::max_instances 原因被拒绝。

DDS_REJECTED_BY_SAMPLES_LIMIT 

数据样本由于 DDS_ResourceLimitsQosPolicy::max_samples 原因被拒绝。

DDS_REJECTED_BY_SAMPLES_PER_INSTANCE_LIMIT 

数据样本由于 DDS_ResourceLimitsQosPolicy::max_samples_per_instance 原因被拒绝。

enum DDS_SampleStateKind

该类型表示数据样本的被读取状态。

数据样本被读取状态是数据读者为底层保存的数据维护的一个状态信息，表明该样本是否被用户通过 DataReader::read 系列方法获取访问成功过。当用户 调用 DataReader::return_loan 方法归还数据样本时， 数据变为 DDS_READ_SAMPLE_STATE 状态。

枚举值
DDS_READ_SAMPLE_STATE 

该数据样本已经被用户访问过。

表示用户曾通过 DataReader::read 系列方法访问过此样本并且已经通过 DataReader::return_loan 方法归还。

DDS_NOT_READ_SAMPLE_STATE 

该数据样本未被用户访问过。

表示用户未曾通过 DataReader::read 系列方法访问过此样本或者还未通过 DataReader::return_loan 方法归还空间。

enum enum DDS_ViewStateKind

此枚举变量列举出了数据实例的视图状态，与 DDS_ViewStateMask 结合使用。

视图状态是数据读者为数据类型中的每个数据实例关联的一个状态信息，通过 DDS_SampleInfo::view_state 返回给用户。此状态信息会随着数据读者对该数据实例的数据以及该实例的生命周期变化而改变。

枚举值
DDS_NEW_VIEW_STATE 

此状态表示数据读者尚未访问过此数据实例下的数据样本或这个数据实例发生了再现（从NOT_ALIVE状态重新变为ALIVE状态）。

DDS_NOT_NEW_VIEW_STATE 

此状态表示数据读者访问过此实例的数据（且此实例未发生再现）。

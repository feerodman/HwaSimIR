DCPSDLL DDS_ReturnCode_t DDS_WaitSet_wait ( DDS_WaitSet *  self,
DDS_ConditionSeq *  activeConditions,
const DDS_Duration_t *  timeout 
)

阻塞等待等待集合中的条件处于触发状态。

应用线程等待某些条件的发生，堵塞调用线程， 当调用成功时，activeConditions 中存放触发的条件， 不允许多个线程等待同一个等待条件。

参数
[in,out]self指向目标。
activeConditions出口参数，用于存储处于触发状态的条件。
timeout指明最长等待时间。
返回
当前可能的返回值：
  • DDS_RETCODE_OK :出口参数有效，表明处于触发状态的条件；
  • DDS_RETCODE_PRECONDITION_NOT_MET :在多个线程上等待条件；
  • DDS_RETCODE_BAD_PARAMETER / DDS_RETCODE_ERROR ：用户提供的空间不足，且底层扩容失败；
  • DDS_RETCODE_TIMEOUT : 在指定的时间内没有条件处于触发状态。
示例:
DataReceiveByWaitSet/main_sub.c, GetPlainStatus.c , 以及 Wait-Condition.c.

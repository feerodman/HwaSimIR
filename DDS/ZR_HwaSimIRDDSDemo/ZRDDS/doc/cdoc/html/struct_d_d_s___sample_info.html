详细描述

数据读者为每一个接收到的数据维护的样本信息。

此信息会在使用 DataReader::read/take 获取数据时与取出的样本样本一同提供给用户。

示例:
ExtendInterface/app1.c, ExtendInterface/app2.c, SecurityExample/ac_example_sub.c, SecurityExample/auth_example_sub.c, SecurityExample/encry_example_sub.c, SimpleInterface/SimpleInterfaceBytesTypeSub.c, SimpleInterface/SimpleInterfaceZeroCopySub.c, TCPConcurrentTransmission/SimpleInterfaceBytesTypeSub.c, TCPConcurrentTransmission/SimpleInterfaceZeroCopySub.c , 以及 UDPLargePackageZeroCopy/SimpleInterfaceBytesTypeSub.c.

结构体成员变量说明

DDS_Boolean valid_data

此值为true表示为数据样本，即该样本信息对应的数据样本有效。

警告
用户在遍历数据样本序列时，使用数据样本之前，需要判定 valid_data == true 。

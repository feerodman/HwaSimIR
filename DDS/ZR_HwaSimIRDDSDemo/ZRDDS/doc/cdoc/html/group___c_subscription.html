该方法在订阅者下创建一个数据读者子实体，并设置关联的主题、QoS以及监听器。

用户使用该数据读者从域内读取/获取指定主题数据，返回的数据读者对象为数据读者关联的用户数据类型相关的数据读者的父类指针， 用户需要将返回值动态转化为用户数据类型的数据读者对象，具体代码参见 subscription_example.c 。 。

参数
[in,out]self指向目标。
[in,out]topic关联的主题描述，用户可以关联主题以及基于内容过滤的主题， 该主题描述必须在调用该方法之前在同一个域参与者下调用 DDS_DomainParticipant_create_topic DDS_DomainParticipant_create_contentfilteredtopic 方法创建的主题的父类；
qos表示为该数据读者设置的QoS， DDS_DATAREADER_QOS_DEFAULT 表明使用订阅者中保存的默认的QoS。
[in,out]listener为该订阅者设置的监听器，此参数可以为空。 ZRDDS不会接管监听器对象的内存管理，由用户负责释放。
mask设置应用程序感兴趣的状态，只有应用程序感兴趣的状态发生变化时，才会通知应用程序。
返回
非NULL表示创建成功，否则表示失败，失败的原因可能为：
  • topic 不是有效的主题对象；
  • topic 的父实体与该订阅者不属于一个域参与者实体；
  • qos 中含有无效的QoS或者含有不一致的QoS配置；
  • 分配内容错误等未归类错误，详细参见日志。
示例:
BatchQos/main_sub.c, CreateDisabledEntity.c, DataReceiveByFilter/main_sub.c, DataReceiveByListener/main_sub.c, DataReceiveByWaitSet/main_sub.c, DeadLineQos/main_sub.c, DurabilityQos/main_sub.c, GetMatchedStatus/main_sub.c, LifespanQos/main_sub.c, LivelinessQos/main_sub.c, OwnershipQos/main_sub.c, PartitionQos/main_sub.c, RapidIOQos/main_sub.c, subscription_example.c, SubscriptionMatchedStatus/main_sub.c, TimeBasedFilterQos/main_sub.c, TransportConfigQos/main_sub.c , 以及 UseSequenceDataType/main.c.

该方法返回的样本顺序参见 DDS_PresentationQosPolicy 。 data_values 以及 sample_infos 两个 序列必须具有相同的 长度（ FooSeq_get_length 下简称len）、最大长度（ FooSeq_get_maximum 下简称max_len）、 是否拥有空间（ FooSeq_has_ownership 下简称own） 三个属性，否则将返回 DDS_RETCODE_PRECONDITION_NOT_MET 错误。 当该函数返回成功时，dataValues 以及 sampleInfos 的这三个属性也相同，且下标相同的样本以及样本 信息相对应。

当 max_len == 0，则表明用户没有提供样本空间，该方法将以“租借”（零拷贝，返回数据的指针）的方式填充 dataValues 以及 sampleInfos ，即own属性设置成false，len设置为获取到的样本数量， 当用户使用完返回的数据样本时应该调用 FooDataReader_return_loan 方法归还这些空间；

当 max_len > 0 && own == true 时，则表明用户提供了样本空间，该方法将底层存储的数据样本以及 对应的样本信息拷贝到提供的空间中，len表示拷贝的样本个数，max_len保持不变，这些数据样本序列无需归还， 但为了统一用户的使用习惯，调用 FooDataReader_return_loan 亦可，底层会忽略本次调用。 当 max_samples <= max_len 时，该方法至多获取 maxSamples 个样本， 当 max_samples > max_len 时，该方法将返回 DDS_RETCODE_PRECONDITION_NOT_MET 错误。

[in,out]dataValues输入输出参数，保存从数据读者中读取的样本序列结果；

viewMask指定目标数据样本的视图状态集合的掩码；
instanceMask指定目标数据样本的所属实例的实例状态集合的掩码；
返回
当前可能的返回值如下：
  • DDS_RETCODE_OK :表示取出数据成功；
  • DDS_RETCODE_PRECONDITION_NOT_MET :参数中存在错误；
  • DDS_RETCODE_NO_DATA :表示当前没有满足条件的数据；
  • DDS_RETCODE_ERROR :表示未知错误导致的读取错误。

- 使用获取主题数据 系列函数时，应判断返回值是否成功，否则容易造成程序异常；

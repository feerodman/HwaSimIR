本模块定义核心接口定义的序列相关的函数接口。

函数说明

DDS_Boolean FooSeq_append ( struct FooSeq *  self,
const Foo *  newValue 
)

向序列尾部添加数据。

参数
[in,out]self指明目标。
newValue指明需要添加的数据。
返回
true表示成功，false表示失败，失败的原因可能为：
  • 序列尚未初始化；
  • 序列的空间是租借的；
  • 当前长度已达最大长度。
DDS_Boolean FooSeq_clear ( struct FooSeq *  self)

清空序列内的所有元素，并将长度与最大长度设置为0。

参数
[in,out]self指明目标。
返回
true表示成功，false表示失败，失败的原因可能为：
  • 序列的空间是租借的，此时调用 FooSeq_unloan() 方法清空。
DDS_Long FooSeq_compare ( const struct FooSeq *  self,
const struct FooSeq *  src 
)

比较当前序列与指定序列的大小关系，包括元素内容，其中元素的比较方法由宏 TCOMPARE 指定。

参数
[in,out]self指明目标。
src指定的序列。
返回
0表示两者相等，小于0表示self <src ，大于0表示self >src
DDS_Boolean FooSeq_ensure_length ( struct FooSeq *  self,
DDS_ULong  length,
DDS_ULong  max 
)

同时设置序列的最大长度以及当前长度，参见 FooSeq_set_length() 以及 FooSeq_set_maximum() 。

参数
[in,out]self指明目标。
length新的当前长度。
max新的最大长度。
返回
true表示成功，false表示失败，失败的原因可能为：
  • 序列尚未初始化；
  • 序列的空间是租借的；
  • 新的当前长度大于新的最大长度；
  • 分配空间失败。

返回

DDS_Boolean FooSeq_set_length ( struct FooSeq *  self,
DDS_ULong  newLength 
)

设置序列的长度，新元素将调用元素的初始化元素。

参数
[in,out]self指明目标。
newLength新长度。
返回
true表示成功，false表示失败，失败的原因可能为：
  • 新长度大于序列的最大长度。
DDS_Boolean FooSeq_set_maximum ( struct FooSeq *  self,
DDS_ULong  newMax 
)

重新设置序列的最大长度。

参数
[in,out]self指明目标。
newMax新的最大长度。
返回
true表示成功，false表示失败，失败的原因可能为：
  • 序列尚未初始化；
  • 序列的空间是租借的；
  • 分配新的空间失败；
注解
该函数可能造成大量的数据拷贝。

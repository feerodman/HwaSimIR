详细描述

template<typename T, typename TSeq>
class DDS::ZRDDSDataReader< T, TSeq >

ZRDDS提供的订阅者模板类，用于提供强类型安全接口的数据读者接口。

模板参数
T用户定义数据类型，例如： Foo
TSeq用户定义数据类型序列，例如： FooSeq

模板参数T为用户定义数据类型，TSeq用户定义数据类型序列，本模板仅定义数据读者中与主题关联的数据类型相关的接口， 其余与类型无关的接口直接使用父类 DDS::DataReader 的即可。

示例:
ExtendInterface/app1.cpp , 以及 ExtendInterface/app2.cpp.

Long  max_samples,
SampleStateMask  sample_mask,
ViewStateMask  view_mask,
InstanceStateMask  instance_mask 
)

该接口从数据读者底层获取用户样本数据。

该方法返回的样本顺序参见 DDS_PresentationQosPolicy 。 data_values 以及 sample_infos 两个 序列必须具有相同的 长度（ FooSeq::length 下简称len）、最大长度（ FooSeq::maximum 下简称max_len）、 是否拥有空间（ FooSeq::has_ownership 下简称own） 三个属性，否则将返回 DDS_RETCODE_PRECONDITION_NOT_MET 错误。 当该函数返回成功时，data_values 以及 sample_infos 的这三个属性也相同，且下标相同的样本以及样本 信息相对应。

当 max_len == 0，则表明用户没有提供样本空间，该方法将以“租借”（零拷贝，返回数据的指针）的方式填充 data_values 以及 sample_infos ，即own属性设置成false，len设置为获取到的样本数量， 当用户使用完返回的数据样本时应该调用 return_loan 方法归还这些空间；

当 max_len > 0 && own == true 时，则表明用户提供了样本空间，该方法将底层存储的数据样本以及 对应的样本信息拷贝到提供的空间中，len表示拷贝的样本个数，max_len保持不变，这些数据样本序列无需归还， 但为了统一用户的使用习惯，调用 return_loan 亦可，底层会忽略本次调用。 当 max_samples <= max_len 时，该方法至多获取 max_samples 个样本， 当 max_samples > max_len 时，该方法将返回 DDS_RETCODE_PRECONDITION_NOT_MET 错误。

参数
[in,out]data_values输入输出参数，保存从数据读者中读取的样本序列结果；
[in,out]sample_infos输入输出参数，保存从数据读者中读取的样本信息序列结果；
max_samples指明本次操作最多从底层读取的样本个数；
sample_mask指定目标数据样本的访问状态集合的掩码；
view_mask指定目标数据样本的视图状态集合的掩码；
instance_mask指定目标数据样本的所属实例的实例状态集合的掩码；
返回
当前可能的返回值如下：
  • DDS_RETCODE_OK :表示取出数据成功；
  • DDS_RETCODE_PRECONDITION_NOT_MET :参数中存在错误；
  • DDS_RETCODE_NO_DATA :表示当前没有满足条件的数据；
  • DDS_RETCODE_ERROR :表示未知错误导致的读取错误。
注解
- 使用获取主题数据 系列函数时，应判断返回值是否成功，否则容易造成程序异常；
  • 在使用参数返回的数据时，应检查相应的 DDS_SampleInfo::valid_data 是否有效；

template<typename T , typename TSeq >
ReturnCode_t DDS::ZRDDSDataReader< T, TSeq >::return_loan ( TSeq &  data_values,
SampleInfoSeq &  sample_infos 
)

该方法用于应用归还从数据读者租借的空间。

为了简化应用的使用，数据读者提供参数有效性检查，参数无效返回 DDS_RETCODE_PRECONDITION_NOT_MET 当归还成功后，序列的最大长度以及长度属性设置为0，拥有空间设置为true。检查的有效性包括：

  • 传入的样本序列是否为通信中间件租借出去的，如果是，则进行归还操作，否则直接忽略；
  • 传入的样本序列是否完整以及样本信息以及样本是否一一对应；
  • 传入的样本序列是否属于该数据读者，如果是，则继续归还；
参数
[in,out]data_values从 read take 系列方法中返回的参数。
[in,out]sample_infos从 read take 系统方法中返回的参数。
返回
当前可能的返回值如下：
  • DDS_RETCODE_OK :表示成功；
  • DDS_RETCODE_PRECONDITION_NOT_MET :表示传入的参数不满足条件。
